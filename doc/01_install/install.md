## SDCC
Compilador que necesitarás para compilar tu juego.

[DESCARGAR](https://sdcc.sourceforge.net/).

Instálalo y en el caso de windows recuerda marcar la opción de añadirlo al path del sistema (Viene marcada por defecto).

## SMS Game Maker
Este engine.

[DESCARGAR](https://juntelart.itch.io/sms-game-maker)

## Tiled
Editor de mapas.

[DESCARGAR](https://www.mapeditor.org/).

## Editor de imágenes
Para crear tus imágenes para el juego (spriteset, tileset, screens...) necesitarás un editor de imágenes.
Puedes usar cualquiera, solo tienes que recordar usar lam paleta de colores de la Master System o Game Gear dependiendo de para que plataforma estés desarrollando el juego.
